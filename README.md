### 🌟 Visão Geral da Arquitetura & UI

Portfólio interativo concebido como um sistema operacional desktop de última geração (macOS 26 Tahoe). O projeto integra um motor óptico proprietário de **Liquid Glass** com desfoque dinâmico de alta densidade, refração realista, profundidade tridimensional e uma experiência adaptativa *Edge-to-Edge* para dispositivos móveis inspirada nas diretrizes nativas do iOS.

### 🛠️ Stack Tecnológica & Engenharia de Front-End

- **Core:** React 19, TypeScript, Vite
- **Estilização & Design System:** Tailwind CSS v4, variáveis customizadas em CSS puro para refração óptica.
- **Efeitos Visuais:** `backdrop-filter: blur()`, saturação dinâmica e suporte a múltiplos modos de exibição (Light/Dark Theme oficial).
- **Deploy & CI/CD:** Vercel (Produção contínua e otimização global de borda).

### 🚀 Guia de Inicialização Local

Para rodar o projeto em sua máquina de desenvolvimento:

```bash
# 1. Clone o repositório
git clone [https://github.com/fabiorodrigues-tech-dev/portfolio-liquid-glass-experience.git](https://github.com/fabiorodrigues-tech-dev/portfolio-liquid-glass-experience.git)

# 2. Acesse a pasta do projeto
cd portfolio-liquid-glass-experience

# 3. Instale as dependências
npm install

# 4. Inicie o servidor de desenvolvimento
npm run dev
